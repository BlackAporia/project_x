1. Доступ до GitHub

Бот працює в GitHub Actions цього репозиторію, а сайт керує ним через ваш токен. Токен зберігається лише в цьому браузері й надсилається тільки на api.github.com.

Як створити токен
  1. GitHub → Fine‑grained tokens → Generate
  2. Repository access: Only select repositories → цей репозиторій.
  3. Permissions → Repository: Actions, Secrets, Variables — Read and write.
  4. Скопіюйте токен сюди. Термін дії обирайте короткий (30–90 днів).

2. Гаманець Cartridge

Ви підтверджуєте в Cartridge сесію з мінімальними правами: лише ходи (commit_actions) і зарахування результату (verify_game) у Loot Survivor. Без переказів. Ключ сесії одразу шифрується в секрет репозиторію.

…або EVM‑гаманець (Ronin, MetaMask)

Власники Ronke грають акаунтом, яким керує їхній Ronin‑гаманець (Game Account), і саме на нього приходять щоденні ігри Ronke Casino. Щоб бот грав цим акаунтом: на lootsurvivor.io увійдіть Ronin‑гаманцем → меню акаунта → Share session → оберіть термін → скопіюйте посилання і вставте сюди. Сесія не може переказувати токени; газ оплачує lootsurvivor.io.
